# 📈 AI Stock Market Analysis and Prediction

An AI-powered NSE stock market analytics dashboard built using Machine Learning, Streamlit, Technical Indicators, and Financial Data Analysis.

This project provides real-time stock analysis, AI-based next-day price prediction, candlestick visualizations, technical indicators, and trading signals for NSE-listed stocks.

---

# 🚀 Features

## 📊 Real-Time NSE Stock Analysis
- Dynamic NSE stock selection
- Searchable stock dashboard
- Real-time financial market data using yFinance

## 🤖 AI-Powered Stock Prediction
- Random Forest Machine Learning model
- Next-day stock price prediction
- Model performance metrics
- Prediction accuracy evaluation

## 📈 Technical Indicators
- RSI (Relative Strength Index)
- MACD Indicator
- SMA 20 & SMA 50
- Daily Returns Analysis

## 🕯️ Advanced Financial Visualizations
- Candlestick Charts
- Interactive Plotly Charts
- Moving Average Trends
- Market Overview Dashboard

## 📢 AI Trading Signals
- BUY / SELL / HOLD signals
- RSI + MACD crossover logic
- AI-based market movement prediction

## 🚀 Market Overview
- Top Gainers
- Top Losers
- Price movement analysis

# ▶️ How to Run the Project

## Step 1 — Clone Repository

```bash
git clone https://github.com/ravikiranjatav/AI-Stock-Market-Analysis-and-Prediction.git
```

## Step 2 — Open Project Folder

```bash
cd AI-Stock-Market-Analysis-and-Prediction
```

## Step 3 — Install Dependencies

```bash
pip install -r requirements.txt
```

## Step 4 — Run Streamlit Dashboard

```bash
streamlit run streamlit_app.py
```
